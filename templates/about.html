ABOUT THE PROJECT

Career decisions need
structure, not noise.

CareerForge is an AI-based career chooser platform designed as an academic AI project with a practical user workflow.

THE PROBLEM

Generic advice is easy to get.

Students often know what career they want but not what to learn first, which skills they are missing, or how to turn learning into portfolio evidence.

THE SOLUTION

One profile → one action plan.

CareerForge uses an AI model to analyze the student's current state against their goal and produce a structured roadmap.

SYSTEM PIPELINE

How the AI works

01

Input

Education, experience, skills, interests, goal and time available.

02

Analyze

Gemini identifies role requirements and high-impact skill gaps.

03

Structure

The response is forced into a fixed roadmap schema instead of open-ended chat.

04

Validate

Resource links are checked against the platform's curated library.

Academic project note: AI-generated guidance should be treated as a planning aid. Course availability, prerequisites and career requirements can change, so users should verify details before acting on them.
